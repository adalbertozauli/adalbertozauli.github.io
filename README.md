# Adalberto Zauli | Digital Health & Clinical AI

Site profissional bilíngue (português/inglês) de Adalberto Zauli, publicado em **https://zauli.med.br** via GitHub Pages (domínio definido em `CNAME`).

Contato: contato@zauli.med.br

## Páginas

- `index.html`: página principal
- `apac-digital.html`: estudo de caso do APAC Digital
- `assets/`: logomarca, retrato e imagem Open Graph (`og-image.jpg`, 1200×630)
- `robots.txt` e `sitemap.xml`: indexação

## Deploy

Settings > Pages > Deploy from a branch > main > /(root). O arquivo `CNAME` mantém o domínio `zauli.med.br`; não alterar DNS sem necessidade.
