# Adalberto Zauli | Digital Health & Clinical AI

Site profissional bilíngue (português/inglês) com projetos Calculadora APS, APAC Digital e QuotaPie.

Publicação planejada: https://adalbertozauli.github.io

## Deploy

Enviar `index.html`, `assets/` e `.nojekyll` para a raiz do repositório e configurar Settings > Pages > Deploy from a branch > main > /(root).
